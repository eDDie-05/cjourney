# C Tutorials

A collection of **C programming tutorials and examples** designed to help beginners learn the fundamentals of the C programming language step by step.

## Topics Covered

### 1. Introduction to C

* What is C?
* Installing a C compiler
* Writing your first C program
* Compiling and running a program

### 2. Variables and Data Types

* Variables
* `int`
* `float`
* `double`
* `char`
* Constants

### 3. Input and Output

* `printf()`
* `scanf()`
* Reading user input
* Formatting output

### 4. Operators

* Arithmetic operators
* Relational operators
* Logical operators
* Assignment operators
* Increment and decrement

### 5. Conditional Statements

* `if`
* `if...else`
* `else if`
* `switch`

### 6. Loops

* `for`
* `while`
* `do...while`
* Nested loops

### 7. Functions

* Creating functions
* Function parameters
* Return values
* Function prototypes

### 8. Arrays

* One-dimensional arrays
* Multi-dimensional arrays
* Searching and processing arrays

### 9. Strings

* Character arrays
* String input
* String manipulation
* Common functions such as `strlen()`, `strcpy()`, and `strcmp()`

### 10. Pointers

* Pointer basics
* Addresses and dereferencing
* Pointers and functions
* Pointers and arrays

### 11. Structures

* Creating structures
* Accessing structure members
* Arrays of structures
* Nested structures

### 12. File Handling

* Opening files
* Reading files
* Writing files
* Appending data
* Closing files

### 13. Dynamic Memory

* `malloc()`
* `calloc()`
* `realloc()`
* `free()`

## Example Program

```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");

    return 0;
}
```

## Compile and Run

Using GCC:

```bash
gcc main.c -o main
```

Run on macOS/Linux:

```bash
./main
```

On Windows:

```bash
main.exe
```

## Learning Goals

By completing these tutorials, you should be able to:

* Understand C programming fundamentals
* Write and compile C programs
* Work with arrays, strings, and structures
* Use functions and pointers
* Read and write files
* Build practical command-line applications
* Develop larger C projects independently
